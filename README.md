## Features
- Add Task
- View Tasks
- Edit Task
- Delete Task
- Update Status

## How to Run
1. Clone the repository
2. Run `composer install`
3. Copy `.env.example` to `.env` and set your database credentials
4. Run `php artisan key:generate`
5. Run `php artisan migrate`
6. Run `php artisan serve`
